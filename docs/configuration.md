# 设备、场景和验收口径

## 360 吨级演示设备

默认外形长 5.25 m、宽 4.50 m、高 3.75 m，耳轴中心距 3.90 m。参数来源按组保存为「仿真假设」「企业提供」或「现场标定」。出厂配置的全部参数为仿真假设。

| 配置组 | 主要字段及含义 |
|---|---|
| `tank` 罐体 | 外形、内腔轮廓、直立液面参考高度、罐口高度、倾转轴、耳轴中心距及出渣槽的宽度、下凹与伸出长度。 |
| `arm` 扒渣机 | 基点、横梁高、扒渣板尺寸、底缘贴面量、包络余量、四轴的上下界/初值/速度和禁入盒。 |
| `tilt` 倾翻 | 初始倾角、作业倾角、允许上下界、角速度、单次调整角度和规划器是否可提出倾罐。 |
| `camera` 相机 | 分辨率、帧率、安装位置与视线、焦距与主点、畸变、可选设备到相机 4×4 刚体外参、录像平面标定、帧龄、遮挡、可信度、设备反馈延时和噪声。 |
| `slag` 残渣 | 基础膜浓度、高浓度区域分布、参考网格、覆盖阈值、漂移、扰动和贴面收集份额。 |
| `objectives` 优化 | 面积去除率、时限、铁损上限、带出渣量/铁损/扰动/耗时/漂移权重，以及计算和反馈的时间参数。 |

设备坐标以米为单位，Z 向上，出渣槽位于罐体局部负 Y 侧，X 沿倾转轴。扒渣机位于槽口外，沿负 Y 方向回拉。罐体绕耳轴倾翻，铁水仍取水平面，截面由内腔和倾角近似计算。默认工作倾角为 10°，仅用于仿真。真实设备的作业角、液位与扒渣板参数待标定。 [工业扒渣设备工艺](https://www.dango-dienenthal.com/en/products/series/deslagging-machines/)

## 动态区域和候选动作

1. 模拟器维护接近满面的连续浓度场，初始薄膜上叠加浓淡起伏。流场移动渣层，邻域混合守恒地转移浓度。每次只收集接触带中的一部分，扒渣板越过槽口到罐外时计入排渣。
2. 虚拟相机将渣层浓淡、设备和液面投影成图像，并叠加噪声与蒸汽。感知端从图像逆投影浓度图和轮廓，规划端使用观测图、轴状态、预算与累计预测风险。
3. 动作先单独倾罐。新帧到达后，规划器才选择高位伸入、贴面、沿水平液面回拉、从槽口越口排渣和退回的轨迹。候选变化包含带道、回拉弧线、速度和底缘贴面量。
4. 提交前检查行程、可见性、剩余时间、液面与槽口高差，以及板、杆、横梁与罐体的碰撞。回拉阶段的板底缘受浅接触带约束。仅允许通过出渣槽到达罐外。
5. 每段反馈后刷新图像并重规划。录像中断、帧过期、严重蒸汽或低可信度使执行器在段边界安全保持。

中途预览从实际仿真采样获取配对的设备姿态与相机帧，识别覆盖层显示在有识别输出的首帧和反馈帧。回放保留全部动作、保持和人工干预事件。

## 报告

固定验收按 120 秒与 98% 覆盖面积去除率判断，配置目标另检查铁损风险。覆盖面积按统一参考网格中高于阈值的单元统计，倾角改变不会凭投影面积自动增加去除率。首轮通常仍接近满覆盖，同时平均浓度下降。报告分别列出覆盖面积、浓度、累计渣量指数、残余网格和时间。指数使用归一化仿真量，现场待测。

三维场景为参数化几何与简化动力学。现场接入需企业提供内腔/CAD、设备行程与控制协议、相机标定及同步的炉次、视频、设备动作和测量结果。实测时间、面积去除率和铁损用于现场验证。

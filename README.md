# 熔线 · 铁水罐扒渣路径规划平台

单套 360 吨级参考设备的本地三维仿真与路径规划操作台。工程集成了 YOLO 录像识别、配置管理、单段执行与反馈、时间轴回放、策略比较和验收报告。安装依赖后可以直接运行仿真。录像识别需要导入录像与标注并训练模型，或提供已有的项目权重。

## 启动

在已安装项目依赖的 Windows 上双击 [start.bat](start.bat)。服务启动后访问 [本地操作台](http://127.0.0.1:18765)。也可以在本目录下运行以下命令。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 server.py
```

首次在其他机器运行时，可先创建隔离环境。已用 Python 3.13 在 Windows 验证。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.bat
```

如端口被占用，可运行 `.\start.bat --port 18766`，再访问对应端口。界面、识别和仿真均在本机运行，设备状态接口监听本机回环地址。已训练的模型可在 CPU 推理，安装匹配的 CUDA 版 PyTorch 后会自动使用 NVIDIA GPU。 [PyTorch 安装说明](https://pytorch.org/get-started/locally/)

## 操作

| 页面 | 操作 |
|---|---|
| 实时作业 | 选择仿真相机或原始录像。仿真可单步、连续运行、暂停和重置。点击候选路径查看评分、排除原因和带时间的轴轨迹。暂停后可扰动残渣或模拟相机故障。 |
| 设备配置 | 编辑设备、罐体、相机、优化权重和参数来源，复制、导入或保存版本。标定入口支持录像原始像素到设备液面坐标的变换。 |
| 数据与训练 | 导入录像和 LabelMe ZIP，检查配对、时间及类别。选择整段验证录像，训练和查看分割指标。验证完成后部署唯一活动模型。 |
| 仿真实验 | 选择调试或验收工况、设置种子和策略，或对固定六工况运行批量比较。 |
| 过程回放 | 选择归档，拖动时间轴查看同步相机帧、姿态、候选、预测去除量和真值面积变化。 |
| 结果报告 | 查看作业总时间、面积去除率、动作次数、模拟铁损、残余面积分布与停止原因。可导出单次及批量 JSON。 |

默认打开「调试 · 满面渣层」。选择 **执行一段** 首先倾罐，再次执行会在水平液面回拉扒渣板，经过出渣口后把带出的渣计入接渣槽。回拉前后可比较覆盖率与归一化平均浓度。点击候选可查看轨迹，**显示速度** 只控制画面播放倍速。

导入录像并且有活动模型后，打开 **录像分段规划**，填写原视频片段起点和结束时间。可把下一次机械臂动作的录像时刻填为结束时间。系统从片段读取帧，先做 CLAHE 增强，再用 YOLO26s-sem 分割。右侧三维与左侧视频同步，绿色线条表示推荐回拉和排渣轨迹。暂停后可点击 **演示路径**，在当前帧的三维设备上播放参考动作。

每秒从可用观测重新评分，选择满足碰撞、行程、时限和铁损约束的最高分候选。片段表显示截止时间与端到端耗时，结果可导出 JSON。缺少现场标定时采用相对投影，轨迹从参考设备待机姿态开始。

仿真以整段动作为执行单元。暂停会暂停当前画面的播放，并在继续前保持下一段待提交。相机故障在提交前的安全复核及执行后的新帧反馈处处理。

## 单独导出增强切片

系统安装 FFmpeg 并将其加入 PATH 后，可在仓库目录运行以下命令。起止时间用秒表示，支持恒定帧率源录像，导出的 MP4 保持原分辨率、帧率和帧序。

```powershell
.\.venv\Scripts\python.exe -X utf8 .\enhance_slag_video.py .\input.avi .\clip.mp4 --start 48 --end 60
```

## 验收与复现

默认参考线是总时间 **≤ 120 秒**，表面积去除率 **> 98%**。模拟器维护独立的连续浓度场，以超过覆盖阈值的参考网格计算面积，去除率为 `1 - 结束覆盖面积 / 初始覆盖面积`。报告单独列出浓度、归一化渣量指数和首轮覆盖率。作业计时包含识别、规划、倾罐及工具运动、反馈和安全保持。所有默认设备和工艺参数标为 **仿真假设**，现场状态为 **现场待验证**。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m slag.benchmark
.\.venv\Scripts\python.exe -B -X utf8 -m slag.benchmark --strategy balanced --strategy coverage --strategy gentle --output reports/comparison.json
```

默认命令运行六项验收工况，生成 reports/acceptance.md 和 reports/acceptance.json。仿真种子、完整配置、轨迹及各时间分项随报告保存。相同输入复现面积采样和演化随机序列。计算时间超过配置下限时按实测计入，接近截止时间的作业会受机器负载影响。已保存的交互归档可原样回放。
